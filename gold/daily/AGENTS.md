# 每日黄金研报目录专属规则（daily/）

本目录存放所有每日早报（07:30）、午报（11:30）、晚报（18:00）、周末专项版 Markdown 源稿、面向读者的公开可证伪预测记分卡（`SCORECARD.md`）、编辑宪章 `DAILY_FORMAT_SPEC.md`、迭代账本 `CHANGELOG.md`、独立审计账本 `AUDIT_LOG.md`（支持按月归档至 `archive/{AUDIT_LOG,CHANGELOG}_YYYY_MM.md`）以及 RSI 进化资产（`RSI_PLAYBOOK.md` / `rsi_metrics.json`）。所有面向读者的最终页面由 `scripts/build_site.py` 直接渲染为纯网页响应式静态门户（含 480+ 交互 K 线、对称 `3×2` 六市场驾驶舱与 `#sec-policy-calendar` 前瞻日历，不生成离线二进制文档附件）。以下规则叠加在仓库根编排宪章 `../../AGENTS.md`、子轨规则 `../AGENTS.md` 与外置日历 `../market_calendar.json` 之上。

## 2. 收敛主刊（`>= 2026-11-26_1800`）专属内容与小白友好三层标准

- **精炼收敛在线主刊**：每日 07:30 早报、11:30 午报与 18:00 晚报均发布结构紧凑的收敛主刊（配 3 张 640px 标准矢量图 + 1–2 张 `DAILY_VISUAL` 零碰撞矢量信息图，同步维护 `index_matrix` 多锚点），聚焦过去 24 小时（或本时段）核心驱动、今日 A/B/D/C 行动细节与 10 万/1 万元双刻度钱包账、关键谣言证伪、**全量重要一手官源政策/地缘要闻覆盖（取消旧 1–2 条上限：同步录入 `equity/state/policy_calendar.json`，首页 `#sec-policy-calendar` 精选 6–9 条、黄金单页 `#sec-market-news` 无上限全量呈现，核心走完 5 环传导链）**与 **4 列未来 7–14 天全北京时间财经与政策日历表**（与 `equity/state/policy_calendar.json` 及门户 `#sec-policy-calendar` 同步，纯中文级别徽章如重磅/重要，零裸 `P0`/`P1`，严守黄金红灯锁），信息密度高、不水字数。
- **小白友好三层递进与全篇零内部词**：按 **「30 秒红绿灯白话结论 → 10 万/1 万元钱包实算与三步怎么买 → 机构级硬核证据与官方自查」** 组织正文；`DXY`/`COT`/`CDS` 及 `DFII10`/`2Y−FF`/`ON RRP`/`HY/CCC OAS`/`IOPV`/`bp` 首次出现必配简短白话括注或交由站内术语浮窗；**全篇（含第二、三部分与全部组件）严禁泄露内部文件名、版本号（`V2.x/V5.x/V6.x/V7.x`）与工程术语（`Subagent`/`红队`/`法证`/`*.py`）**；严禁居高临下说教口号（`小白词典`/`直接抄`/`蠢事`/`1 分钟定心丸`/`保命铁律`），鼓励平等温和的「3 分钟速读结论」「关键词白话速查」；Layer 0–1 零感叹号、全篇 ≤5 个感叹号；加粗密度 ≤14%，裸数字不套反引号。
- **禁止搬运主报告与惰性加载**：切勿把主报告已有的 55 年历史通缩/通胀长河、12 大投行完整目标价长表或全流程开户/回购百科原文复制到日报中，仅在必要时做一句衔接提示；常规班次只需读取 `../master_snapshot.json` 核验主报告 5 大触发条件，仅命中阈值需同步修订主报告时才全量读取主报告 MD。
- **封面 KPI、信号/噪音与可选组件**：`DAILY_META` 支持 **4 张高密度核心 KPI 卡**（`.kpi-strip.cols-4`，兼容 4–6 张），每条 `sub` 严格控制在 **≤17 个汉字当量**；`DAILY_SIGNAL_NOISE` 渲染为 `.sn-grid` 双栏网格（手机端单栏堆叠）；`DAILY_TRUST_BAR` 与 `DAILY_GLOSSARY` 为可选（0–1 次），按需使用不硬塞。

## 3. 本目录公开记分卡、双账本、月度归档与 RSI 自进化资产细则

1. **`SCORECARD.md`（公开可证伪预测记分卡）**：面向读者完全公开透明，每刊发刊同步回验到期预判（`✅ 兑现` / `⚠️ 部分兑现` / `❌ 证伪` / `⚪ 条件未触发`）并追加新追踪项，**历史记录零篡改**；全文严禁出现任何内部工程/RSI/脚本文件名词汇，由 `lint_readability.py` 强制校验。
   - 新刊与同场修订分别在公开记分卡、变更簿、核验账本留同期编号（`GOLD_EDITION_SCORECARD` / `GOLD_EDITION_CHANGELOG` / `GOLD_EDITION_REVIEW`）。结案以原刊锁定的时点、区间和证据口径为准，待披露项继续挂账并交下一班。台账格式见[黄金快照契约](../../.agents/skills/gold-research-publishing/references/directives-and-snapshot-schema.md)。
2. **`CHANGELOG.md`（迭代演进总账）**：每发一刊，通过微型补丁 `_ledger_patch.json` + 预授权 `scripts/patch_state_dbs.py --prepend-gold-ledgers` 在文件最顶部无损头插本刊完整相对路径（如 `daily/YYYY-MM-DD_1800_晚报_黄金深度研报.md`）及红队四张清单【新增 / 更新 / 修正 / 删除】；跨月膨胀时写 `_archive_patch.json` 经 `--archive-gold-ledgers` 将上月条目无损归档至 `daily/archive/CHANGELOG_YYYY_MM.md`（归档 + 活跃合并保留全部历史非空行原序）。
3. **`AUDIT_LOG.md`（独立核验与审计账本）**：同样通过 `_ledger_patch.json` + `scripts/patch_state_dbs.py --prepend-gold-ledgers` 无损头插本期 `GOLD_EDITION_REVIEW` 与「三大信任资产」（拦截谣言/误区清单、模型与策略升级清单、细节校准清单及 `0/N` 核心结论影响说明）及一手官方数据库索引；跨月经 `_archive_patch.json` + `--archive-gold-ledgers` 无损归档至 `daily/archive/AUDIT_LOG_YYYY_MM.md`（保留历史非空行原序）；**严禁将版本 Diff 表、子代理调研路数、内部文件名或分析师人名消歧塞入日报正文**。
4. **`RSI_PLAYBOOK.md` 与 `rsi_metrics.json`**：每班次待双轨（Step 3 黄金 + Step 4 权益）均通过 `--strict` 严检后进入 **Step 5**，由 **1 路统一独立只读盲审子代理**联合复盘黄金与三地权益（独立单跑黄金轨时单独盲审），完成 6 维打分（`/30`，第 4 维聚焦**纯网页视觉清晰度、SVG 零碰撞与小白 3 分钟可读性**）与上期预判验真，自动执行 Tier A 通过 `_rsi_patch.json` + `scripts/patch_state_dbs.py --append-gold-rsi` 无损追加 `rsi_metrics.json` 并滚动精炼 `RSI_PLAYBOOK.md`（软限 **≤180 行** / 硬上限 **200 行**防膨胀，由 `lint_readability.py` 强制校验）及按需慎改 Tier B（Tier C 含 `../../AGENTS.md` 与 `../AGENTS.md` 仅写提案）。随后复跑双轨 `--strict`，按根契约登记发布阶段并由 `scripts/publish_site.py --edition-token <token>` 统一发布本班次纯网页门户。每满 10 刊汇总 Meta-RSI 趋势并向用户呈报 Tier C 升级提案。
