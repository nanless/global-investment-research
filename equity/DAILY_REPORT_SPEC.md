## 四、三市独立休市/半日市调度与 `_r2` 跨午夜切割线

1. **三模式独立调度**（每日对照 `state/market_state.json` 未来 60 天休市日历与 `holiday_and_rollover_sop.md` 判定）：
   - **模式 1（三市均正常开市）**：A 股、港股、美股全部按 `main`（≥2 张矢量图）标准出版；
   - **模式 2（局部休市或半日市）**：正常开市市场发 `main`，受影响市场发升级版 `holiday_watch`（建议 ≥1 张矢量图）。**美股在 `07:30` 与 `11:30` 均按前一日美东交易日（`day - 1`）判定**：例如单日工作日美股假日且次日仍为工作日（如感恩节、马丁·路德·金日、总统日、阵亡将士纪念日）可覆盖当日 `1800` 及次日 `0730`、`1130`；元旦 `2027-01-01_0730` 与 `2027-01-01_1130` 美股承接 12/31 常规交易日官收正常发 `main`、A/港复用，`2027-01-01_1800` 及 `01-02_0730` 三市齐休复用；
   - **模式 3（三市齐休）**：无 P0/P1 突发时不发冗余日报，仅更新 `INDEX.md` / `CHANGELOG.md` 守望提示与周日三大深研库/记分卡校准。
2. **同场次防覆写（`_r2`）与 `05:30 CST` 跨午夜切割线**：同日同场次补发一律追加 `_r2`，北京时间 `05:30` 前归前日 `1800_r2`，`05:30` 起归当日 `0730`。
3. **开工前生成计划**：运行 `python3 equity/lint_equity.py --plan YYYY-MM-DD_HHMM[_rN]` 计算目标班次（支持 `0730` / `1130` / `1800`）；例外情形（`source_outage` / `breaking_event` / `revision_reuse`）按既定规范结构化登记并在下班次清除。
4. **日历与跨轨空值**：假日/周末或美东非 VIX 窗口（含 `07:30` 与 `11:30`）无有效盘中观测时，双轨 `brent_live_usd` 与 `vix_live` 允许同时留空（`vix_live` 留空时均不得保留 `vix_live_as_of` 与 `vix_intraday_high`）。
